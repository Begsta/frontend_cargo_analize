# Показ лабораторной №5

Запустите `npm install`, `npm run build`, `npm run dev`. Откройте адрес Vite.
Ниже сценарий получения настоящих скриншотов; сами изображения ещё не сняты.

| № | Что снять и объяснить |
|---|---|
| 1 | `/`: видеолента и DevTools → Network. Включить Disable cache, обновить страницу: видны локальные видео и изображение, запросов API нет. |
| 2 | `/catalog`: плитка и Network. Выбрать 2,0 т, нажать «Отобрать»: остаются грузы массой от 2,0 т. Фильтрация не вызывает HTTP-запросов. |
| 3 | `/cargo_addition`: экран добавления и Network. Переход прямым адресом; у гостя оба пункта меню и поля создания отключены. |
| 4 | Плитка с изображениями по умолчанию. Показать пустые `image` в `src/data.ts`. |
| 5 | `DEFAULT_IMAGE` и `Media` в `src/components/Media.tsx`: `cargo.image || DEFAULT_IMAGE`, состояние ошибки и `onError`. |
| 6 | `src/components/CargoFilters.tsx`: `value`, `onChange`, `onApply`; управляемый ползунок и отправка формы без перезагрузки. |
| 7 | `src/pages/Catalog.tsx`: два состояния массы, передача обработчиков и `filter`. Движение ползунка меняет выбранное значение, кнопка применяет его. |
| 8 | `Media.tsx` и `Catalog.tsx`: `useState`; `useEffect` в Media сбрасывает ошибку при изменении груза/ссылки. |
| 9 | `Feed.tsx` и `App.tsx`: `useParams`, `useSearchParams`, `useEffect` для заголовка. Объяснить все зависимости эффектов. |
| 10 | README: запуск, страницы, кнопки, поля и ссылки на расчёт. |

## Проверка перед показом

- Плитка: 0 т — 9 грузов; 2 т — 6 грузов; 10 т — пустой результат.
- Сдвиг ползунка без «Отобрать» не меняет карточки.
- Карточка открывает соответствующий груз в ленте; описание раскрывается на месте.
- «Далее» переключает груз, после девятого возвращает первый.
- Видео по умолчанию воспроизводится; в Network нет ошибок загрузки медиа.
- Два пункта навигации доступны, «Добавление» и «Вход» отключены.
- При ширине 430 px нет горизонтальной прокрутки; оформление сверяется
  с шаблонами предыдущей лабораторной.
- Расчёт `hardware.html` помещается на один лист A4 при печати без колонтитулов.

Третья страница в задании не названа: использован уже существующий экран
добавления из предыдущей работы, без реализации создания и авторизации.
Основное требование «только mock без бэкенда» принято вместо противоречащей
ему вводной фразы о подключении веб-сервиса. Никаких запросов API нет.
